GeoSort – Guida rapida

GeoSort ordina le feature di un layer vettoriale e assegna un numero progressivo sort_order (1 = prima feature nell'ordine scelto).

Criteri di ordinamento

  • Attributo / espressione – ordina per il valore di un campo o per il risultato di un'espressione QGIS personalizzata.
    Clicca il pulsante ε per aprire il Field Calculator. Esempi:
    • combinazione di campi: "area_kmq" / "pop"
    • funzioni geometriche: length($geometry), area($geometry)
    • condizioni: CASE WHEN "tipo"='A' THEN 1 ELSE 2 END
    L'espressione attiva è evidenziata in verde; clicca [×] per rimuoverla.
  • Coordinate centroide – per X, Y o distanza da un punto di riferimento
  • Proprietà geometrica – area, perimetro, lunghezza, numero di vertici, bounding box
  • Posizione lungo linea – tre modalità:
    • proiezione centroide – tutte le feature
    • solo intersecanti – via centroide proiettato
    • solo intersecanti – via primo punto di contatto

Output

  • Aggiorna il layer corrente – aggiunge o aggiorna il campo sort_order
  • Nuovo layer in memoria – crea una copia ordinata senza modificare l'originale
  • Opzione: aggiungi sort_value con il valore del criterio usato

Suggerimenti

Usa Anteprima per verificare l'ordine prima di applicare le modifiche.
  • Valori NULL: scegli se posizionarli in cima o in fondo
CRS geografico: i calcoli di area e lunghezza sono in gradi². Si consiglia la riproiezione in un CRS proiettato prima di applicare il criterio.
